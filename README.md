# Databricks Git Practice

This repository contains hands-on Git and GitHub practice examples collected in the `src` folder.

## Contents

- `basic-commandas` - Basic branch and staging commands
- `git-add` - Adding files to the staging area
- `git-bisect` - Finding the commit that introduced a problem
- `git-branch` - Creating and managing branches
- `git-clone` - Cloning a repository
- `git-Config` - Git configuration basics
- `git-init` - Initializing a repository
- `git-log` - Viewing commit history
- `git-stashing` - Temporarily shelving changes
- `git tag` - Creating and using tags
- `cherry-pick` - Applying a selected commit
- `Git-workflow` - A typical Git workflow
- `gitignore` - Ignoring files with `.gitignore`
- `merge-conflict` - Practicing merge conflict resolution
- `Databricks-Link` - HTML page with a Databricks-related link

Most examples are visual notes and screenshots for learning and revision.

## Getting Started

Clone the repository and open the `src` folder:

```bash
git clone https://github.com/avinash4tripathi/git-practice.git
cd git-practice
```

Then open the examples in VS Code or a browser. The HTML demo is located at `src/Databricks-Link/index.html`.

## Notes

Local environment files such as `.env` are excluded from version control.
